# Семейный компас

Десять игр с вопросами, ориентирами, ассоциациями и карточками крайностей. Сайт находится в docs/.

Публикация: Settings → Pages → Deploy from a branch → main → /docs → Save.

Изображения перечислены в assets-manifest.json. Перед публикацией необходимо сохранить их в docs/assets. scripts/import_assets.py выполняет однократное копирование и не заменяет уже существующие файлы.

Известная ошибка исходника: в теме ЗОЖ для вопросов 3 и 4 указана одна картинка крайностей. Сохранено без изменения; требуется правильная карточка вопроса 4.
