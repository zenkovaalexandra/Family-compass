# Семейный компас

Десять интерактивных игр с исходными вопросами, ориентирами и иллюстрациями. Главная страница: `docs/index.html`.

Первый запуск GitHub Actions «Import compass illustrations» сохраняет 206 иллюстраций в `docs/assets`. Уже сохранённые изображения повторно не загружаются. После успешного импорта сайт не обращается к Тильде.

Для публикации: Settings → Pages → Deploy from a branch → main → /docs → Save.

Исходные тексты и порядок выбора вопросов сохранены. Для каждого вопроса показывается только карточка «Две крайности». Карточки ассоциаций и переключатели убраны. Картинки открываются крупнее в новой вкладке. Дополнительные материалы доступны под игрой. Состояние вопросов хранится отдельно для каждой темы.
